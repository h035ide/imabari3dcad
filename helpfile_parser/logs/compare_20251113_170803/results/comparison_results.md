```
データムとは、3次元モデル上で位置や向きなどの基準に使う要素のことです。図面ドキュメントには存在せず、3Dモデル内で参照や配置の基準として使います。

主なデータム要素（コンテキストにあるもの）
- 平面：3次元空間上の無限平面。XY/YZ/ZX 平面などの原点基準の平面が常に存在。既存平面やフェイス、座標系軸から作成したり、3点や基準点＋法線で作成できます。作成時はプレビューが出てOKで確定し、定義に使った要素に追従させる（関連）ことも可能。
- 座標系：3次元の座標系。絶対座標系が常に存在し、いずれかがワーク座標系（作業座標系）に設定されます。座標値入力はワーク座標系基準になります。座標系の作成・表示やワーク座標系の設定ができます。
- 軸：3次元空間上の無限直線。平面の交線や基準点＋方向などで定義でき、プレビュー後に確定します。定義要素に追従させることも可能。
- 点：3次元空間上の点。位置を指定して作成し、関連付けで定義要素の変更に追従させられます。
- 投影点：既存の点をカーブ・エッジ・フェイスなどに投影して作る点。投影方向を指定でき、未指定時は最短点で投影されます。複数選択可で、関連付けも可能。

要するに、データムはモデル内の位置・向きの基準を与える要素群で、ジオメトリ作成や寸法・拘束の基準として使われます。
```

### beautifulsoup_default
**実行時間**: 12.36秒

**回答**:
```
データムとは、3Dモデル内で位置や方向などの基準となる参照要素のことです。図面ドキュメントには存在せず、モデリング時の基準や拘束に使います。主な種類とポイントは次のとおりです。

- 平面（Plane）
  - 無限平面。原点のXY、YZ、ZX平面は常に存在します。表示シンボルを持ち、任意に作成できます。  
- 座標系（Coordinate system）
  - 3次元の座標系。絶対座標系は常に存在し、常にいずれかがワーク座標系（作業座標系）になります。座標値の入力はワーク座標系に対して行います。作成やワーク座標系設定が可能です。  
- 軸（Axis）
  - 3次元空間上の無限直線。軸要素、2平面の交線、基準点と方向指定などで作成できます。  
- 点（Point）
  - 空間上の点。位置を入力して作成し、必要に応じて元要素に追従する関連付けができます。  
- 投影点（Projected point）
  - 点をカーブ・エッジ・フェイスなどに投影して作る点。投影方向を指定しなければ最短での投影になります。こちらも関連付けが可能です。

また、多くのデータムは「関連」オプションを付けて、定義に使った要素の変更に追従させることができます。用途としてはスケッチやフィーチャーの位置・向きの基準、拘束の基準などに使います。
```

### langchain_chroma_default
**実行時間**: 13.85秒
**取得ノード数**: 5

**回答**:
```
座標系は主に次の方法で作成します。用途や入力方法に応じて使い分けてください。

1) 任意位置（マニピュレーターで作成）
- 座標系作成コマンドを起動するとマニピュレーターが表示されます。  
- マニピュレーターを移動・回転して位置と向きを決め、OKをクリックすると座標系が作成されます。  
- 必要に応じて「ワーク座標系に設定」をチェックすると、作成した座標系をワーク座標系にできます。  
- 左上のチェックボックスで要素名や要素グループの指定が可能です。

2) データム（原点と2軸指定）で作成
- 座標系の原点（位置入力）と2軸（方向入力）を指定します。  
- 座標軸定義でどの軸ペア（XY, YZ, ZX）を定義するか選びます。  
- 入力が整うとプレビューが表示されるので確認してOKを実行します。  
- 「関連（オプション）」を付けると、定義に使った要素の変更に追従させられます。  
- 要素名・要素グループの指定や「ワーク座標系に設定」のチェックも可能です。

補足
- ワーク座標系に設定された座標系は色で表示されます（色は設定で変更可）。  
- ワーク座標系は必ず1つ存在します。モデル構成ウィンドウや選択コマンドで座標系を選び、コンテキストメニューの「ワーク座標系に設定」を実行して切替えられます。
```

### beautifulsoup_default
**実行時間**: 30.21秒
**取得ノード数**: 5

**回答**:
```
作成方法は主に2通りあります。手順と主なパラメータは次のとおりです。

1) パラメータ入力で作成（原点＋2軸を指定）
- コマンドを起動して、座標系の原点（位置入力）と2軸（方向入力）を設定します。  
- 「座標軸定義」で定義する軸ペアを選択（XY／YZ／ZX）。  
- パラメータがそろうと作成座標系のプレビューが表示されるので確認してOKで作成。  
- オプション：  
  - 「ワーク座標系に設定」にチェックすると作成座標系がワーク座標系になります。  
  - 「関連」を有効にすると、定義に使った要素の変更に追従します。  
  - 左上のチェックボックスで要素名指定や要素グループへの追加が可能。

2) マニピュレーターで任意位置に作成
- 「座標系の定義（任意位置）」コマンドを起動するとマニピュレーターが表示されます。  
- マニピュレーターを移動・回転して位置・向きを決め、OKで作成。  
- 同様に「ワーク座標系に設定」「要素名」「要素グループ」「関連」などのオプションが使えます。

補足
- ワーク座標系は必ず1つだけ存在し、モデル構成ウィンドウや選択状態からコンテキストメニューの「ワーク座標系に設定」で切り替えられます。  
- ワーク座標系は色で表示され（色は設定で変更可）、表示サイズも設定できます。
```

1. 「配管系統リストの読込」を実行して対象の系統を読み込む。

5. 問題なければOKボタンで実行する。  
6. （必要に応じて）集計結果をCSVで出力する場合は、OKをクリックして出力先のCSVファイル名を指定する。
